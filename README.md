# Zoo management assignment

My university project where we were to create a zoo management app in console that can record, edit, and delete animals in a zoo.

## About

A few sentences explaining:
- Add, remove, edit animals in the zoo
- read and write animals to a file for saving and loading on exit
- added a visitor who can buy items if he has the funds
- made as part of a university assignment

## Features

- Add, remove, edit animals added to zoo
- get random facts about the animals
- view animals that have been added
- prefrom daily care for the animals
- search through animals by name or colour
- display a zoo report
- visit zoo stores and buy items if you have the funds
- add funds for visitor

## Technologies

- Java
